# 專案測試範本 (Test Project v1.0)

本專案為自動化測試與環境部署所建立的標準 README 範本，旨在驗證解析器效能與排版正確性。

## 功能特點
* **極簡架構**：移除冗餘程式碼，僅保留核心測試邏輯。
* **快速部署**：支援一鍵安裝依賴，縮短環境建置時間。
* **跨平台相容**：完美運行於 Linux、macOS 與 Windows 環境。

## 快速開始

### 1. 安裝依賴
```bash
npm install --save-dev jest
```

### 2. 執行測試
```bash
npm run test
```
